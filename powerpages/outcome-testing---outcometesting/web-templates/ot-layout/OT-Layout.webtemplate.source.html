Weights are Light 300, Regular 400, Medium 500, SemiBold 600. The stylesheet carries a version querystring so a browser holding the previous file picks up changes without a hard refresh. Bump it on EVERY change to outcome-testing.css, not only a material one - a browser holding the old file is not told what changed, and the deploy succeeds either way, so the omission looks exactly like a CSS rule that does not work. Every page script that calls the Web API uses it, and Check-PortalTemplates.ps1 (rule F) fails a template that reads the error body itself. window.otApi.ok(xhr) true only for a 2xx from the Web API itself, so a request bounced to the sign-in page is not success window.otApi.error(action, xhr) " failed. " - the action in the user's words, from the call site ("Signing off") window.otApi.refusal(xhr) the plug-in's own sentence, prefix taken off, or '' The why is the plug-in's own sentence when the body carries one of the refusal prefixes CommandHelpers.cs throws.
