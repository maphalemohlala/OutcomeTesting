## The TEST runbook, in this order

The order is the whole point. **`CaseAccessPlugin` travels with the solution and refuses every
case, review and remediation write where the two teams or the AQS Team account are missing** -
so the principals go in first, or TEST stops taking writes the moment the import activates the
steps.

From the repo root, in PowerShell:

```powershell
$env:DOTNET_ROLL_FORWARD='Major'; $R='plugins\OutcomeTesting.Registration\bin\Debug\net8.0\OutcomeTesting.Registration.exe'; $T='https://org37995f36.crm11.dynamics.com'

# 1. The AD-218 principals: two owner teams and the AQS Team account. Idempotent.
& $R ensureaccessprincipals $T --confirm $T

# 2. The import. If pac reports AADSTS50173, run `pac auth create` first (it opens a browser).
#    --activate-plugins is not optional: without it the steps arrive disabled.
pac solution import --environment "$T/" --path artifacts\2026-09-24-test-promotion\OutcomeTesting_1_0_10_0_managed.zip --activate-plugins --async

# 3. Every step on the assembly present and enabled. Expect 0 missing, 0 disabled.
& $R verifysteps $T

# 4. The teams' own privileges, so the Code App's case shares resolve.
& $R grantteamsecurity $T

# 5. The batch's data: CRP and E4-03 on the N/A scale, Q-GR-02 v2 (DEV's id), S-CD help text.
#    Needs the import first - 120910012 and 120910013 do not exist in TEST until then.
& $R webapimany $T "@artifacts\2026-09-24-test-promotion\test-data.json"

# 6. The access backfill: a dry run, then the real one. Paste any UNMATCHED or FAILED line.
& $R reconcileaccess $T
& $R reconcileaccess $T --confirm $T
```

**7. The AQS reviewers' account - the owner's decision.** The AQS queue is Account-scoped, so
a reviewer reads it only while their contact's parent account is "Outcome Testing - AQS Team".
In TEST six contacts hold AQS Reviewer and **none has a parent account**: Adam Strumidlo,
Service Account, Zoe Ramwell, Suresh Gautam, Ruth Maxwell, Simunye Radingwana. The four who
also hold Administrators read everything regardless; **Suresh Gautam and Ruth Maxwell will see
an empty queue until this is done.** The simplest route is to remove and re-grant the AQS
Reviewer web role on each in the Power Pages admin screens: `AqsQueueMembershipPlugin`, which
arrives with this import, sets the account on the grant.

Then hand back, and the agent verifies: solution 1.0.10.0, 55+ steps enabled, the data read
back, the portal templates and css as committed, the Code App `appversion` moved, and both
