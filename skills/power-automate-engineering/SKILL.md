# Power Automate Engineering

## Required context
Read `../../knowledge/project-context.md`, `../../knowledge/knowledge-sources.md`, and `../../knowledge/phase-skill-map.md` before acting.

## Instructions
Define trigger, trigger conditions, inputs/outputs, connection reference, environment variables, concurrency, idempotency key, retry policy, timeout, scopes, error path, logging and owner. Use child flows for reusable logic. Avoid hidden dependencies on maker connections. Make flows solution-aware. Implement notifications, assignment, escalation, remediation and export orchestration only where automation is required. Always provide test cases and operational runbook entries.

## Required output
- Decisions and assumptions
- Files/components changed
- Tests or verification evidence
- Risks and rollback notes
- Requirement IDs affected
