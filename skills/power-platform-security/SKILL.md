# Power Platform Security

## Required context
Read `../../knowledge/project-context.md`, `../../knowledge/knowledge-sources.md`, and `../../knowledge/phase-skill-map.md` before acting.

## Instructions
Map Entra groups to Dataverse owner/access teams and security roles. Apply least privilege. Define table privileges, scope, field security where justified, append/append-to, assign/share and ownership. Include multi-role collision analysis. Submitted Tax/AQS sections must not be edited by downstream roles. Produce positive and negative tests for every role and lifecycle state. Never put credentials, tokens or personal data in fixtures, logs or source.

## Required output
- Decisions and assumptions
- Files/components changed
- Tests or verification evidence
- Risks and rollback notes
- Requirement IDs affected
