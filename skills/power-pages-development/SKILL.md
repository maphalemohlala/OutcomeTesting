# Power Pages Development

## Required context
Read `../../knowledge/project-context.md`, `../../knowledge/knowledge-sources.md`, and `../../knowledge/phase-skill-map.md` before acting.

## Instructions
Use VS Code, Git and approved PAC/Power Pages tooling. Define authentication, web roles, table permissions, forms/lists, Liquid/web templates, site settings, CSP, accessibility and ALM. Never rely on UI hiding for security. Test anonymous, authenticated, cross-contact and cross-account access. Keep portal configuration in source and deploy through managed solutions and environment-specific settings. If Code Apps replace Power Pages for a feature, do not duplicate it.

- Risks and rollback notes
