# Test Quality Release

## Required context
Read `../../knowledge/project-context.md`, `../../knowledge/knowledge-sources.md`, and `../../knowledge/phase-skill-map.md` before acting.

## Instructions
Create tests from acceptance criteria: unit tests for code and pure rules; integration tests for Dataverse/connectors/flows; security matrix tests; routing state tests; import/export reconciliation; accessibility; performance; deployment smoke tests; UAT. No completion claim without command output or recorded test evidence. Classify defects, retest fixes and verify no regression. Produce release notes, known issues, support runbook, rollback decision points and hypercare checks.

## Required output
- Decisions and assumptions
- Files/components changed
- Tests or verification evidence
- Risks and rollback notes
- Requirement IDs affected
